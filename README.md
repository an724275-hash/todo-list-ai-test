# Список задач

Небольшое тестовое задание на HTML, CSS и JavaScript. Можно добавлять задачи, отмечать выполненные и удалять их. Список хранится в `localStorage` браузера.

Демо: https://an724275-hash.github.io/todo-list-ai-test/

## Запуск

Откройте `index.html` в браузере. Сборка и установка пакетов не нужны.

## Инструменты

При разработке использовал Codex для подготовки кода и проверки интерфейса. Логику и результат проверил вручную в браузере.
